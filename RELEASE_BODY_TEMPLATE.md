## Which ZIP should I download?

All versioned filenames end with `vX`, where `X` represents the version included in this Release.

### Players

Download:

`Demeterio_NotebookInjector_PLAYER_vX.zip`

Use this archive when you only want to install and use Notebook Injector in The Sims 4.

```text
Demeterio_NotebookInjector_PLAYER_vX.zip
├─ Demeterio_NotebookInjector_Script_vX.ts4script
├─ Demeterio_NotebookInjector_Generic_vX.package
├─ Demeterio_NotebookInjector_Debuglog_.package
├─ Demeterio_NotebookInjector_Installation_vX.txt
├─ Demeterio_NotebookInjector_Compatibility_vX.txt
└─ Demeterio_NotebookInjector_ModUpdateChecker_vX.package
```

The installation method and current compatibility information are included inside the ZIP.

**Highly recommended:** for receiving mod update notifications, download and install Mod Update Checker by Demeterio.
Find it here: https://github.com/Demeterio/Mod-Update-Checker/releases/latest

### Mod creators

Download:

`Demeterio_NotebookInjector_MODDER_vX.zip`

Use this archive when you want to use Notebook Injector with your own mod.

```text
Demeterio_NotebookInjector_MODDER_vX.zip
├─ Demeterio_NotebookInjector_Script_vX.ts4script
├─ Demeterio_NotebookInjector_Generic_vX.package
├─ Demeterio_NotebookInjector_Debuglog.package
├─ Demeterio_NotebookInjector_TestingCustom_vX.package
├─ Demeterio_NotebookInjector_Installation_vX.txt
├─ Demeterio_NotebookInjector_Compatibility_vX.txt
├─ Demeterio_NotebookInjector_ModUpdateChecker_vX.package
├─ Documentation/
│  └─ Demeterio_NotebookInjector_Modder_Guide_vX.pdf
└─ XML_Examples/
```

The MODDER ZIP contains the same runtime files as the PLAYER ZIP, plus the complete modder guide and some examples.

**Highly recommended:** for receiving mod update notifications, download and install Mod Update Checker by Demeterio.
Find it here: https://github.com/Demeterio/Mod-Update-Checker/releases/latest

Do not bundle the core files inside your mod archive. Direct players to the official Mod The Sims,
SimFileShare or GitHub download page.

## Source code for this Release

To inspect the source code corresponding to this exact Release, select the matching release tag from the branch and tag selector, then open the `src/` folder.

The direct URL follows this format:

```text
https://github.com/Demeterio/Notebook-Injector/tree/<RELEASE_TAG>/src
```

Replace `<RELEASE_TAG>` with the tag of this Release, for example `v1.1.0`.
