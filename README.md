# Demeterio: Notebook Injector

A mod for **The Sims 4**, created by Demeterio.

## Download

The latest version of the mod is available in the **Releases** section of this repository.

## Installation

1. Download the latest version from the Releases section.
2. Extract the archive if necessary.
3. Place the `.package` and `.ts4script` files in your The Sims 4 `Mods` folder.
4. Enable **Custom Content and Mods** and **Script Mods Allowed** in the game options.
5. Restart the game after changing these settings.
